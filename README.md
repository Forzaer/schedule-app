# Расписание — Telegram Mini App

Интерактивное расписание групп **МК1** и **ИБО-24** в одном файле `index.html` (HTML + CSS + JS).
Файл ничего не загружает со сторонних сайтов (ни telegram.org, ни шрифтов), поэтому открывается сразу.

- выбор группы при первом запуске (запоминается);
- дни недели свайпом или кнопками, переключение недель, кнопка «Сегодня»;
- пара «идёт сейчас» с прогрессом, окна между парами;
- нижняя панель с деталями пары (время, преподаватель, аудитория, тема, материалы);
- тёмная тема по умолчанию и светлая по кнопке, стеклянный (glassmorphism) дизайн.

## Хостинг (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
Через минуту приложение откроется по адресу `https://forzaer.github.io/schedule-app/`.

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` (если бота ещё нет).
2. `/newapp` → выберите бота → название, описание, картинка 640×360 → URL `https://forzaer.github.io/schedule-app/`.
3. По желанию: `/mybots` → бот → Bot Settings → Menu Button → тот же URL, чтобы кнопка «Расписание» была в чате с ботом.

## Как редактировать расписание

Все данные — JSON в блоке `<script id="schedule-data">` в начале `index.html`.

Правила, по которым добавляется новое расписание:

1. **Пары на конкретные даты** (`dates`, например `"2026-10-14": [...]`) остаются как есть и показываются ровно так, как записаны.
2. **Расписание без точных дат** ставится с сегодняшнего дня (того, когда его прислали) по дням недели.
   Всё, что было до этого дня, не меняется.
3. **Нестабильное расписание** (сейчас МК1) не повторяется: в приложении только то, что прислано.
   Новое фото без дат раскладывается по датам на 7 дней вперёд, начиная с дня отправки.
4. **Стабильное расписание** (сейчас ИБО-24: на чётной неделе одно, на нечётной другое) повторяется постоянно через `cycle`.

Поля группы:

- `dates` — пары на конкретные даты, важнее всего остального;
- `cycle` — список постоянных расписаний с датой начала: `[{"start": "2026-10-12", "weeks": [неделя 1, неделя 2]}]`.
  С `start` недели идут по очереди без конца, начиная с недели, в которую попадает `start`; более позднее расписание сменяет более раннее;
- `weekly` — повторяющаяся неделя (`monday` … `sunday`), если она понадобится;
- `extra` — занятия на дату, которые добавляются к парам из `cycle` или `weekly` (так заведены занятия ЦБИ).

Сначала ищется точная дата, затем день недели. Если нет ни того ни другого, приложение показывает «Нет данных».
Пустой список `[]` — «Пар нет».
Поля пары: `num`, `time`, `subject`, `type` (лекция / практика / лабораторная), `teacher`, `room`, `topic`, `link`.

Как заведены группы сейчас:

- **МК1**: только `dates`. 12–16 октября — прежнее фото, 17–23 октября — фото от 17 октября. Дальше «Нет данных», пока не придёт новое.
- **ИБО-24**: `dates` на 5–14 октября, как были; `cycle` с 12 октября из двух недель по боту одногруппника
  (первая — как 12–18 октября, вторая — как 19–25 октября); `extra` — занятия ЦБИ для 3 курса
  из таблицы «Расписание 3 и 4 к осень 2026». Пятница первой недели (как 16 октября) пока не заполнена,
  её не было на скриншотах, поэтому в такие пятницы видны только занятия ЦБИ.

## Если в Telegram видна старая версия

Внизу экрана выбора группы написан номер версии. GitHub Pages кэширует страницу до 10 минут.
Если после обновления номер старый, полностью закройте приложение и откройте снова,
либо поменяйте ссылку в BotFather на `https://forzaer.github.io/schedule-app/?v=2` (число можно менять при каждом обновлении).
