# Расписание — Telegram Mini App

Интерактивное расписание групп **МК1** и **ИБО-24** в одном файле `index.html` (HTML + CSS + JS).

- выбор группы при первом запуске (запоминается);
- дни недели свайпом или кнопками, переключение недель, кнопка «Сегодня»;
- пара «идёт сейчас» с прогрессом, окна между парами;
- нижняя панель с деталями пары (время, преподаватель, аудитория, тема, материалы);
- тёмная тема по умолчанию и светлая по кнопке, стеклянный (glassmorphism) дизайн.

## Хостинг (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
Через минуту приложение откроется по адресу `https://forzaer.github.io/schedule-app/`.

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` (если бота ещё нет).
2. `/newapp` → выберите бота → название, описание, картинка 640×360 → URL `https://forzaer.github.io/schedule-app/`.
3. По желанию: `/mybots` → бот → Bot Settings → Menu Button → тот же URL, чтобы кнопка «Расписание» была в чате с ботом.

## Как редактировать расписание

Все данные — JSON в блоке `<script id="schedule-data">` в начале `index.html`.

- `weekly` — повторяющаяся неделя (`monday` … `sunday`), так заведена **МК1**;
- `dates` — пары на конкретные даты (`"2026-10-14": [...]`), так заведена **ИБО-24**, потому что её расписание меняется от недели к неделе.

Сначала ищется точная дата, затем день недели. Если нет ни того ни другого, приложение показывает «Нет данных».
Поля пары: `num`, `time`, `subject`, `type` (лекция / практика / лабораторная), `teacher`, `room`, `topic`, `link`.
