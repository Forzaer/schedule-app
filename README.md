# Расписание · Telegram Mini App v3.0

Единое расписание **МК1** и **ИБО-24** с выбором группы, календарём, занятиями ЦБИ и стеклянным интерфейсом.

**Приложение:** https://forzaer.github.io/schedule-app/

## Что добавлено

- Адаптивный интерфейс: боковая панель на компьютере и нижняя навигация на телефоне.
- Glassmorphism, светлая и тёмная темы, плавная анимация с поддержкой reduced motion.
- Ближайшая или текущая пара, прогресс занятия, перерывы и недельная сводка.
- Выбор группы с сохранением на устройстве. Старые настройки `sched.group` и `sched.theme` продолжают работать.
- Фильтры «Все пары», «Основное», «ЦБИ», поиск в выбранном дне и избранное.
- Подробности пары: время, преподаватель, аудитория, тема и источник.
- Экспорт выбранной недели в `.ics` для календаря. Скачивание зависит от возможностей браузера Telegram; файл также можно скачать, открыв приложение в обычном браузере.
- Все время, даты и смена суток рассчитываются по Москве независимо от часового пояса телефона.

## Данные

- **МК1:** добавлена неделя **23–28 ноября 2026** по двум большим фото. Пользователь подтвердил, что оба снимка относятся к МК1. Суббота — продолжение той же таблицы. Сокращения «БЖ», «ИЯПД», «ИТПД», «С/у_ТП» сохранены без домысливания расшифровки.
- **ИБО-24:** добавлены точные даты **14, 16, 17, 18, 20, 21 и 23 ноября 2026** из сообщений бота. Преподаватели для совпавших предметов, времени и типа занятий сохранены из предыдущего расписания.
- **ЦБИ:** сохранены **26 дат** сентября–декабря из исходного проекта с темами, преподавателями и аудиториями. Занятие **20 ноября, 10:00–13:00** уточнено по скриншоту и показывается один раз.
- История октября и двухнедельный цикл ИБО-24 сохранены. Для дат, рассчитанных по циклу, показано соответствующее уведомление.

Приоритет: **точная дата → последняя действующая версия цикла → недельное расписание**. Занятия `extra` добавляются к циклу/неделе; точный день уже содержит полный список и не дополняется повторно. Фильтр ЦБИ определяет занятия по полю `kind` либо по упоминанию ЦБИ в аудитории.

Пустой список `[]` означает «Пар нет»; отсутствующий день — «Нет данных». Неизвестные дни и нестабильное расписание МК1 не повторяются автоматически. Новые сведения без даты требуют уточнения даты перед публикацией.

## Разработка

Нужен Node.js 18+. Устанавливать пакеты не требуется.

```sh
node scripts/build.mjs
node --test tests/schedule.test.cjs
node scripts/serve.mjs
```

Предпросмотр: `http://localhost:4173/`.

Исходники:

- `src/schedule.json` — данные, происхождение и версия;
- `src/core.js` — выбор расписания, московское время, экспорт ICS;
- `src/app.js` — интерфейс и взаимодействия;
- `src/styles.css`, `src/shell.html` — оформление и структура;
- `src/telegram.js` — сохранённый локальный мост Telegram без внешнего SDK;
- `tests/schedule.test.cjs` — проверки новых дат, истории, цикла, ЦБИ, часового пояса и ICS.

После редактирования исходников **пересоберите и закоммитьте `index.html`**. Это готовый самостоятельный файл со встроенными данными, CSS и JavaScript: он не загружает внешние шрифты, библиотеки или SDK. GitHub Pages по-прежнему публикует корень `main`; отдельная сборка на сервере не нужна.

## Telegram и публикация

Существующий бот может использовать прежний адрес: `https://forzaer.github.io/schedule-app/`. Токен бота этому статическому приложению не требуется. Сохранены события готовности, раскрытие Mini App, цвет панели, тактильная отдача и кнопка «Назад» для диалогов; добавлена обработка безопасных отступов.

В Settings → Pages должен быть выбран `main` / `(root)`. Если Telegram показывает предыдущую версию, закройте Mini App полностью и откройте снова; при необходимости используйте `https://forzaer.github.io/schedule-app/?v=3` в настройке кнопки бота. Параметры `group` и `date` позволяют открыть конкретную группу и дату, например `?group=МК1&date=2026-11-28`.

Избранное и настройки хранятся только на этом устройстве. Приложение не меняет сообщения бота и не отправляет данные пользователей на сервер.

Интеграция сверена с [документацией Telegram Mini Apps](https://core.telegram.org/bots/webapps). Полная проверка внутри Telegram на реальном телефоне остаётся отдельной от проверки страницы в браузере.
